# Project catalog

Store each application workload under `<project-id>/revisions/<revision-id>/`. Use lowercase hyphenated IDs and explicit revisions such as `v001`.

A project revision owns its application specification, stack, canonical requirements, PM acceptance tests, and starter source. It can support multiple experiments and repeated runs. Different application types belong to different project IDs.

Start from [the project template](../templates/project/README.md). See [repository organization](../docs/repository-layout.md) for ownership, versioning, and run snapshots. No project has been selected or created yet.
