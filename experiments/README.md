# Experiment catalog

Store each experimental design under `<experiment-id>/revisions/<revision-id>/`. A design references one exact project revision and defines the builder matrix, instruction treatments, execution policy, and evidence criteria.

Repeat the same design with new run IDs. Change a factor, requirements baseline, or analysis policy through a new experiment revision; use a new experiment ID for a distinct research question. Record the parent revision and the reason for each variation.

Start from [the experiment template](../templates/experiment/README.md). Templates are drafts, not frozen runnable configurations.
