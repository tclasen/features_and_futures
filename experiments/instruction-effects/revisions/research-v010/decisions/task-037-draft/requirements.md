# Task 037: Directory owner-default filter

Add Project default priority with All, Low, Normal and High, default All. This matches the owning project default, independently of the task priority. Intersect with all other directory conditions in Active and Archived scopes, including Deleted. Current defaults after rename, restoration and imports are used. Matching counts, owner summaries, exports and every bulk action honor the owner-default condition. Viewing or selecting it never changes an owner default or an existing task priority.
