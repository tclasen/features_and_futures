## Requirement029: export the matching directory workspace without changing it

Dependencies: all requirements through028 remain cumulative. Add `Export matching workspace` to Task directory. Download UTF-8 JSON named `workboard-workspace.json` with format `workboard-workspace`, integer version1 and a `projects` array. Include precisely the original owners with at least one currently matching task under all directory scope, completion, priority, due-range and title-search controls. Owners appear in project creation order; each object's tasks appear in that owner's stored order, independent of Directory order. Duplicate project names remain separate objects.

Each project object contains name, archived, defaultPriority and tasks. Each task contains title, completed, priority, dueDate, notes and deleted using the existing project-export types and normalized-LF literal notes. Export only matching tasks, including matching deleted tasks in Deleted filter. An empty resolved result exports an empty projects array. Include no runtime IDs, credentials or another owner's nonmatching tasks. Export changes no data, controls, summaries, order or remembered positions. Existing single-project export continues to include the full project regardless of its local view filters.
