# Task 035: Directory due-date presence

Add Directory due status with All, Dated and Undated, default All. Dated matches nonempty due dates; Undated matches empty due dates. Intersect this with the existing inclusive range and all other matching conditions. An Undated selection with a nonempty date boundary has no matches.
