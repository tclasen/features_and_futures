## Requirement019: global read-only task directory

Dependencies: all requirements through018 remain cumulative. The home page provides `Task directory`, opening a read-only cross-project directory with `Projects` navigation back to the existing home page. Each opening starts with Project scope Active, Task filter All, Priority filter All, empty due range and empty Directory search. No project/task data changes merely by viewing or filtering this directory.

Project scope offers Active and Archived in that order, selecting only tasks owned by projects in that state. Task filter offers All, Open, Completed and Deleted, with the same live/deleted semantics as requirement016. Priority filter offers All, Low, Normal and High. Directory search and `Search directory` match task titles only using the existing ASCII-case, trim and horizontal-whitespace matching rules. Notes and owner names do not match. Due from, Due through and `Apply due range` use the existing inclusive, dated-only validation rules. All filters/search/range intersect, and changing one preserves the others. Opening a different directory starts at the defaults.

Each result has data-testid `directory-task-row`, containing separate `directory-task-title` and `directory-project-name` elements, the original task title and owner name, completion state as Open or Completed, explicit priority, due date (empty when unset), and literal notes. Use separate directory-task-completion, directory-task-priority, directory-task-due-date and directory-task-notes test IDs for those fields. Notes preserve every visible text character and line break; CRLF/LF transport representations are equivalent for display. Results follow project creation order and stored task order within each project, including reserved deleted positions when Deleted is selected. An `Open project` control in each row opens that task's owning project with the existing default project filters; archived owners remain read-only. Directory rows provide no editable task fields. Original and imported tasks participate with their stored values and ownership, including upgraded records.
