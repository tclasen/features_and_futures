## Requirement026: set or clear due dates for matching live directory tasks

Dependencies: all requirements through025 remain cumulative. Add a textbox named `Visible tasks due date` and a `Save visible due date` button. In Active scope and All, Open or Completed task filters, apply one due date to every currently matching live task across its original owners, using all current priority, date-range and title-search intersections. Trim the proposed date, accept only a real Gregorian date in YYYY-MM-DD with year0001–9999, and accept empty input to clear dates. Invalid nonempty input announces `Due date must use valid YYYY-MM-DD` and changes no task or applied controls.

Disable the action in Archived scope, Deleted filter and empty live results. Re-evaluate the unchanged current controls and ordering after success; changed dates may remove tasks from the current range or change Due date order. Update all directory/global/owner/bulk states from that result. Preserve each other task field, owner identity, stored order, remembered positions and project metadata. Duplicate project names remain independent. The saved dates survive reload and actual process restart; earlier individual date/range validation and export/import behavior remain cumulative.
