# Project revision template

Copy this directory to `projects/<project-id>/revisions/<revision-id>/`.

Fill in `project.json` and `SPEC.md`, define the stack and canonical requirements, and prepare the PM acceptance suite and identical starter source. Commit the definition before referencing it from an experiment. Record content hashes in the run snapshot; never reference a moving "latest" revision.

This is a draft template with no selected application.
